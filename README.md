# writemare
WRITEMARE — Local-first screenwriting: linked outline, corkboard, and script in a single offline HTML app. Free to use; keep the name; share improvements.


WRITEMARE keeps writing from becoming a nightmare.
It’s a local-first screenwriting app that runs as a single HTML file in your browser—no account, no cloud required. Outline, corkboard, and script stay linked so structure and pages move together.
Write mode

Outline — beats, act headers, structure templates (e.g. Save the Cat, Hero’s Journey, story circle), page goals, list/board views
Corkboard — scene cards with synopsis, drag reorder, push/pull with outline and script
Script — industry-style screenplay editor (scene headings, action, character, dialogue, parentheticals, transitions), SmartType, focus/typewriter modes, scene numbers, title page, find/replace, stats
Notes — characters, locations, props, continuity, scratch, checkpoints/snapshots

Prep mode (optional)

Breakdown — scene tags and element tracking
Shots — light shot list with sizes, angles, movements; stills/refs
Schedule — stripboard / shoot-day ordering, call sheets & sides

Import / export

Load Fountain, Final Draft (.fdx), PDF, plain text
Save full project (.json), Fountain, FDX, PDF/print
Openable .html — app + project in one double-clickable file
Share a copy for offline handoff; compare collaborator copies (diff only)

Collaboration & extras

Peer-to-peer realtime collab (script + chat; optional camera/mic/screen share)—no central script server
Voice dictation and read-through
Revisions, track changes, checkpoints, beat tracker (page progress)
Light/dark theme, work modes (Write vs Prep), browser AI protection toggle

License

Free to use, copy, modify, and share (including commercial use). Do not rename the app—modified versions must still be WRITEMARE (or “WRITEMARE — modified”). Keep the license notice, and please put improvements back in the repo so others can help make it its best.
